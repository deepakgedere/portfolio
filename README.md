# Deepak Gedere — Portfolio

A responsive, single-page portfolio site for QA automation and software testing work.

## Run locally

Open `index.html` in a browser. The projects section loads the latest public, non-fork repositories from the GitHub API and includes a saved project list if the API is unavailable.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once Pages finishes deploying, the site will be available at `https://deepakgedere.github.io/`.
